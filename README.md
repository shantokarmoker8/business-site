# 🌿 business-site

A modern, professional business website built with **React**, **React Router**, and **Tailwind CSS v4**. Features a clean light green & white theme with full responsiveness and pixel-perfect 100vh section layouts.

---

## 🖥️ Live Preview

🔗 [https://business-site-mu-sage.vercel.app](https://business-site-mu-sage.vercel.app)

---

## ✨ Features

- ⚡ **Vite** — lightning fast dev server & build tool
- ⚛️ **React 19** — component-based UI
- 🛣️ **React Router v6** — client-side routing
- 🎨 **Tailwind CSS v4** — utility-first styling (no custom CSS)
- 🖼️ **Unsplash Images** — real professional photos
- 📱 **Fully Responsive** — mobile, tablet & desktop
- 📐 **100vh Sections** — each section fills the full screen on desktop
- 🔤 **Google Fonts** — Playfair Display + DM Sans
- 🎯 **React Icons** — Remix Icons (ri) set

## 🚀 Getting Started

### Prerequisites

- Node.js **v18+**
- npm বা yarn

### Installation

```bash
# Repository clone করো
git clone https://github.com/shantokarmoker8/business-site.git

# Project folder এ যাও
cd business-site

# Dependencies install করো
npm install

# Dev server চালু করো
npm run dev
```

Browser এ open করো → [http://localhost:5173](http://localhost:5173)
